# POCKET FEVER

**▶ 플레이: https://dowjang.github.io/Pocket-Fever/**

80~90년대 오락실 감성의 2D 포켓볼 로그라이크. 공 하나를 쳤을 뿐인데 충돌의 계보와 공의 유언이 이어지며 점수가 화산처럼 터진다.

- 폰·태블릿은 **가로**로 들고, PC는 **마우스**만으로 플레이합니다 (키보드 사용 안 함).
- 테이블을 눌러 조준 → 왼쪽 **POWER** 바를 누른 채 아래로 당겼다 놓으면 샷.
  당긴 뒤 위로 되밀거나, 옆으로 빼거나, 두 번째 손가락으로 터치하거나, 우클릭하면 취소.
- 오른쪽 **FINE** 휠 = 미세 조준 · **SPIN** = 당점 · 트릭 카드는 눌러서 사용 (길게 누르면 설명).
- 진행은 브라우저에 저장됩니다.
